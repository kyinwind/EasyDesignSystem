# ``EasyDesignSystem``

用统一 SwiftUI 语义 API 构建体验一致的 iOS、iPadOS、macOS 与 Mac Catalyst 界面。

## Overview

EasyDesignSystem 提供设计 Token、主题、Easy API 与精细组件。业务代码描述 Page、Section、Group、Card、按钮和状态等语义，设计系统根据宽度与交互能力解析具体边距、尺寸、表面和交互反馈。

支持范围：

- iOS / iPadOS 17 及以上
- macOS 14 及以上
- Mac Catalyst 17 及以上
