# EDS 0.4.0 按钮风格调整：medium 档取代 outline（描边退役）

> 状态：**方案讨论中，未动码**。
> 需求来源：杨哥 2026-09-21 目视 Catalog 后拍板——不喜欢描边按钮，要求"次要操作不用边框，用背景色，深浅处在主要操作与轻量操作之间"。
> 本文档 = 需求分析 + 技术方案 + 开发计划（按约定三合一）。

## 一、需求分析

### 现状问题

当前 emphasis 四档：`filled 实心 / outline 描边 / soft 12%浅底 / plain 无底`。
描边档是体系里唯一的异类——其余三档全靠"底色深浅"表达强弱，outline 靠线条，两种语言混在一套组件里。

### 目标

四档统一为**底色深浅梯度**，描边从按钮中彻底消失：

| 层级 | 档位 | 视觉 | 强度 |
| --- | --- | --- | --- |
| 主要操作 | `filled` | toneColor 实心 | 100% |
| **次要操作** | **`medium`（新）** | **toneColor 50% 中底 + textPrimary 字** | **~50%** |
| 轻量操作 | `soft` | toneColor 12% 浅底 + 同色字 | 12% |
| 零参数 | `plain` | 无底，纯色字 | 0% |

### 杨哥已拍板的四项决策（2026-09-21）

1. 新档位名 = **`medium`**
2. `outline` 公开枚举值**保留为废弃别名**，内部转发 → VideoHero 44 处源码零改动、只换视觉
3. `soft` 浅底档**保留**，四档梯度完整
4. 描边清理**只限按钮**；`EDSCard`、`EDSSidebarItemButton` 选中态的描边语义不同（容器分隔/状态指示），不在本次范围

## 二、技术方案

### 2.1 枚举与兼容（EDSButtons.swift）

```swift
public enum Emphasis: String, CaseIterable, Sendable, Hashable {
    case filled
    case medium          // 新增
    case soft
    case plain

    @available(*, deprecated, renamed: "medium",
               message: "描边已退役；outline 现渲染为 medium 同款中底色。")
    case outline         // 保留，解析时与 medium 同视觉
}
```

- `EDSResolvedButtonVisual.resolve` 的 switch 中 `case .medium, .outline:` 走同一分支。
- `CaseIterable.allCases` 会包含 outline（5 项）——Catalog 矩阵展示时需过滤或标注废弃。
- 对外源码零破坏：所有 `emphasis: .outline` 调用照常编译（仅废弃告警）。

### 2.2 Role 别名表

| Role | 旧组合 | 新组合 |
| --- | --- | --- |
| `.secondary` | outline + accent + regular | **medium + accent + regular** |
| `.primary` / `.done` / `.danger` | 不变 | 不变 |

### 2.3 medium 档视觉规格

- 底色：`toneColor.opacity(0.50)`（**杨哥定版：50%**——22% 试算与 soft 的 12% 区分不开，
  中间档失去意义；50% 与 12% 拉开明显层次，目视仍可微调）
- 文字色：**`textPrimary`**（近黑/近白自适应）。50% 彩底上继续用同色字对比度必然不达标
  （accent 蓝字在 50% 蓝底约 2:1），无法走 soft 的同色字规则；textPrimary 在浅色外观下
  近黑、深色外观下近白，50% 任何色底上都可读。danger/success 单独异常列入目视验收。
- 边框：无（`borderColor = nil`）
- 深色外观：opacity 公式自适应（soft 已验证此路径），仍列入目视验收
- hover/按压/禁用行为沿用现有通用逻辑，无特例

### 2.4 连锁影响

| 影响面 | 说明 |
| --- | --- |
| 旧 4 个 ButtonStyle | `EDSSecondaryButtonStyle` 内部传 outline → 自动获得 medium 视觉，代码不动 |
| VideoHero 44 处 | 源码零改动；`role: .secondary` 全部由"橙描边白底"变"橙色 22% 中底" |
| API 基线 | 新增 `Emphasis.medium` 符号 → 基线需 `--update-baseline` 重建 |
| UI 测试 | Catalog 矩阵页布局变化，iPhone 审计需重跑（字号/ViewThatFits 铁律勿犯） |
| 版本 | 行为变更 → **minor 0.4.0**（Unreleased 里的 fixedSize 修复一并并入） |
