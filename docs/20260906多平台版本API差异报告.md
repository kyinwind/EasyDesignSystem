## 兼容性说明

- 现有 Page、Section、Group、Card、Button、Pill、Row、Theme 与 Easy API 的公共符号均保留。
- 新增字段采用默认值和兼容解码；旧主题 JSON 不需要迁移即可继续读取。
- 新增交互档案默认使用 `.automatic`，不要求旧调用方修改代码。
- 当前检查以 Swift Symbol Graph 的精确标识符为依据，并由 `Scripts/check-api-compatibility.sh` 自动阻止公共符号删除。
