# 公开自适应与字体 API：分析、方案和开发计划

## 需求判断与范围

SettingsSuite 需要复用 EDS 的交互档案解析、自适应度量和 Dynamic Type 字体角色。现有实现均为内部 API，公开它们符合 EDS 的通用能力边界。保留展示型 `EDSSettingRow`。便捷字体重载读取当前 `edsTheme`，与现有显式传入 tokens 的 API 并存。

## 数据与界面

- 无数据库变更：本项目没有数据库，本次也不修改主题 JSON、持久化格式或默认值。
- 界面无现有渲染变化：现有计算和字体映射保持原样；新增重载供未来调用者读取当前主题。

## 文件与风险

- 修改 `Sources/EasyDesignSystem/EDSAdaptiveEnvironment.swift`：公开档案解析与只读度量 API，补充 pointer 行高说明。
- 修改 `Sources/EasyDesignSystem/EDSScaledTypography.swift`：公开字体角色与显式 tokens 修饰器，新增主题便捷重载。
- 修改 `CHANGELOG.md`：记录 0.2.1，并将已发布条目归入 0.2.0。
- 新增本方案文档。无需修改现有测试、Examples、Package.swift 或数据库文件。
- 风险在于 public API 类型可见性与跨模块编译、四平台 SwiftUI 条件编译。通过外部模块探针、现有测试及平台构建验证。
