# EasyDesignSystem 多平台迁移指南

## 支持范围

- iOS / iPadOS 17 及以上
- macOS 14 及以上
- Mac Catalyst 17 及以上

visionOS 与 tvOS 暂不在本轮支持范围内。

## 从原有 macOS 版本升级

现有 `EDSEasyStyle`、三个 `.easyDesign` 重载、`EDSEasyOptions` 初始化方法、主题配置入口和预设主题 ID 均保持兼容。原有 macOS 调用方通常只需要更新包版本并重新编译。

页面默认边距继续兼容已有 `spacing.md` 和 `spacing.xxl` 定制。当调用方开始配置新的 `adaptiveLayout.compactPagePadding` 或 `regularPagePadding` 后，页面改用明确的自适应值。显式传给 Easy API 的 `padding` 与 `maxWidth` 始终优先于自动规则。

## 统一图像 API

新代码建议只依赖 SwiftUI：

```swift
EDSMultilineSubtitleRow(
    "标题",
    subtitle: "说明",
    icon: Image(systemName: "book")
)
```

原生 macOS 上原有接收 `NSImage` 的初始化方法仍然保留。iOS、iPadOS 和 Mac Catalyst 调用方不需要也不应导入 AppKit。

## 主题 JSON 兼容

旧版完整或部分 JSON 都可以继续解码。缺少新增的 `adaptiveLayout` 时使用以下默认值：

```json
{
  "adaptiveLayout": {
    "compactPagePadding": 16,
    "regularPagePadding": 32,
    "readableContentMaxWidth": 880,
    "minimumTouchTarget": 44,
    "minimumHybridTarget": 44
  }
}
```

新版导出的 JSON 会包含 `adaptiveLayout`。建议保留未知字段，并使用 EasyDesignSystem 的 Codable 类型完成读写，避免业务代码自行裁剪主题文件。

## 平台行为

- iPhone 与 iPad 默认使用 Touch 档案，交互控件至少提供 44pt 命中区域。
- 原生 macOS 默认使用 Pointer 档案，保留紧凑视觉尺寸并支持 Hover。
- Mac Catalyst 默认使用 Hybrid 档案，同时满足触控和指针交互。
- Pill 的删除入口在触控和 Hybrid 环境持续可见，在 Pointer 环境以 Hover 增强。
- `Color.toHex()` 对动态系统颜色统一按浅色外观解析，使同一主题文件的导出结果稳定。JSON 颜色仍保存为静态 RGB，不保留动态浅色/深色语义。

## 高级覆盖

自动档案通常已经足够。测试、Preview 或特殊硬件场景可以局部覆盖：

```swift
SomeView()
    .easyDesignInteractionProfile(.hybrid)
```

应用启动时可通过 `EDSTheme.shared.configure` 调整自适应 Token。主题配置应在主线程、UI 建立前完成；当前版本仍不承诺运行时动态换肤自动刷新所有既有 View。

## 当前限制

- 暂不支持 visionOS 与 tvOS。
- 主题 JSON 只能保存静态 RGB 值，无法往返保留 SwiftUI 动态系统颜色本身。
- 平台自动适配负责设计系统组件；导航结构、窗口命令、菜单和平台专属业务交互仍由宿主 App 负责。
