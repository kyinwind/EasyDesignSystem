## 一、版本口径

按 `CHANGELOG.md` 已固化判据：

> `1.0.0` 前，patch 版本用于**向后兼容的新增**、可见性提升和 Bug 修复；minor 版本用于**有架构意义的节点、行为变更或新的对外模型**。

本次改造同时满足"新的对外模型"（`Emphasis` / `Tone` / `Size` / `EDSButtonAppearance`）与"行为变更"（D16 改变 `.default` 预设语义色）两条 → **版本号 `0.3.0`**（当前最新为 `0.2.1`）。

## 二、阶段划分

六个阶段，每阶段结束都有**可独立验证的产出**与**明确的回滚点**。任一阶段失败不影响已完成的阶段。

### P1 — 实现层收敛（不动任何对外 API）

| 项 | 内容 |
| --- | --- |
| 新增 | `EDSButton.Emphasis` / `.Tone` / `.Size` 三个枚举（`Sendable` + `Hashable` + `CaseIterable`） |
| 新增 | `EDSButtonAppearance` 值对象（public） |
| 新增 | `EDSResolvedButtonVisual`（internal 解析结果）+ `resolved(tokens:profile:horizontalSizeClass:)` 纯函数解析器 |
| 新增 | `EDSButtonStyleCanvas`（internal `ButtonStyle`，承载全部视觉逻辑） |
| 不动 | `EDSButton`、`Role`、4 个旧 ButtonStyle、任何 token |

**此阶段结束后新代码尚未被 `EDSButton` 使用** —— 编译通过即证明新类型自身正确，风险为零。

**验收**：`swift build` 通过；Swift 6 严格并发下零警告。
**回滚点**：`git revert` 本阶段提交，无对外影响。

---

### P2 — 接线：别名表 + 三个 init + 旧 Style 转发

| 项 | 内容 |
| --- | --- |
| 改 | `Role` 新增 `.done`，并实现 `CaseIterable` / `Sendable` / `Hashable` |
| 新增 | `Role → EDSButtonAppearance` 映射（别名表） |
| 改 | `EDSButton` 存储属性由 `role` 改为 `appearance`；新增三维 init；**旧两个 init 签名逐字不动** |
| 改 | `EDSButton.body` 改为 `Button { ... }.buttonStyle(EDSButtonStyleCanvas(appearance:))` |
| 改 | 4 个旧 ButtonStyle 的 `makeBody` 改为转发到 `EDSButtonStyleCanvas`（类型保留 public） |

**关键风险控制**：`emphasis` **绝不给默认值**——给了会让 `EDSButton("确定") { }` 报 `ambiguous use of init`。

**验收**：
- V4：Examples / README 示例代码**不改一行**即编译通过
- V7：`EDSButton("确定") { }` 与 `EDSButton("确定", role: .primary) { }` 均编译通过
- V8：`.primary` 渲染与 `emphasis: .filled, tone: .accent, size: .regular` 完全一致

**回滚点**：本阶段是唯一的"对外行为切换点"，`git revert` 即可整体回到改造前状态。

## 四、构建命令速查（环境相关，复用）

SwiftPM：

```bash
swift build
```

Xcode 工程（**必须前台执行**——后台运行拿不到沙箱放行；且须指定临时缓存路径，否则被沙箱拦截）：

```bash
cd Examples/PlatformCatalog

# macOS
xcodebuild -project EDSPlatformCatalog.xcodeproj -scheme EDSPlatformCatalog \
  -destination 'platform=macOS' -configuration Debug \
  -derivedDataPath /tmp/eds-dd -clonedSourcePackagesDirPath /tmp/eds-csp build

# iOS
xcodebuild -project EDSPlatformCatalog.xcodeproj -scheme EDSPlatformCatalog \
  -destination 'generic/platform=iOS' -configuration Debug \
  -derivedDataPath /tmp/eds-dd-ios -clonedSourcePackagesDirPath /tmp/eds-csp-ios \
  CODE_SIGNING_ALLOWED=NO build
```
